# Explorer 0.13.1

**Export a crash report from Help.** Choose **Help → Export Crash Report…** to save a ZIP with the latest Explorer crash report macOS has recorded. It includes the original report and a summary of the Explorer version, build number, and macOS version recorded at the crash and at export.

You can export a crash from an earlier version if macOS still has the report. Review the ZIP for personal information before sharing it with support.

Existing users can install this release through **Explorer → Check for Updates…**.

Requires macOS 14 or later. One universal download supports Apple Silicon and Intel Macs.
