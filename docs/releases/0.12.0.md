# Explorer 0.12.0

- **Edit the address bar with one click.** Click an empty part of the bar, use the pencil button, or press **⌘L** to select the current path. Breadcrumbs still open their folders.
- **Complete folder paths as you type.** Explorer suggests folders for relative, absolute, and `~` paths. Use the arrow keys to preview a match, **Tab** to complete it and see its child folders, or **Return** or a click to open it.
- **Choose an interface language.** English is built in, and the DMG includes 42 additional language packs. In **Settings → General → Interface language**, follow the primary macOS language with **Automatic (macOS)** or choose a language and click **Apply and Restart**. Partial packs use English for missing strings.

Run **Install Explorer.command** from the DMG to install Explorer and add missing packs. If you update through **Explorer → Check for Updates…**, you can add packs from the DMG's **Localizations** folder using **Settings → General → Install Language Packs…**. Explorer asks before replacing installed packs. See the [language pack guide](https://github.com/binaryquest/MacExplorer/blob/main/docs/LOCALIZATION.md) for custom translations.

Requires macOS 14 or later. One universal download supports Apple Silicon and Intel Macs.
