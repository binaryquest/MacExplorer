# Explorer 0.11.1

- Adds a native **About Explorer** window with the app icon, version and build number, and a short product description.
- Adds links to the [Explorer website](https://explorer.bquick.io), [source code](https://github.com/binaryquest/MacExplorer), and [Binary Quest](https://www.binaryquest.com), along with MIT license attribution.
- Supports closing the About window with ⌘W without closing a folder tab behind it.

Open **Explorer → About Explorer** to see the new window. Existing users can install this release through **Explorer → Check for Updates…**.

Requires macOS 14 or later. One signed and notarized download supports Apple Silicon and Intel Macs.
