# Explorer 0.13.0

- **Create an empty file from the right-click menu.** Choose **New File…** and enter a name, with or without an extension. Explorer protects existing files from being overwritten and supports Undo for new files.
- **Recover when My Drive can’t open.** If macOS may be blocking access to Google Drive, Explorer explains the problem. **Choose a folder…** opens the macOS folder picker so you can select **My Drive** and try again.
- **Choose Explorer as the default for folder opens.** In **Settings → Applications**, select **Set as Default…** for regular folder opens that use the macOS default. Select **Use Finder…** to switch back. **Reveal in Finder** still opens Finder.

Switching the default and restoring Finder were verified on macOS 15.8.2. macOS 27.2.1 rejected the change in testing. Explorer reports the rejection and shows the current default.

Existing users can install this release through **Explorer → Check for Updates…**.

Requires macOS 14 or later. One universal download supports Apple Silicon and Intel Macs.
