# Explorer 0.11.2

- Open a folder in **Terminal**, **iTerm2**, or your preferred terminal from the right-click menu. For a selected file, open its containing folder; right-click empty space to use the current folder.
- Open text, code, JSON, YAML, scripts, and configuration files in **TextEdit** or your preferred editor. Other regular files offer **Open as Text**.
- Choose your terminal and editor in **Settings → Applications**, with installed-app discovery and a **Choose Application…** option. Terminal and TextEdit are the defaults; normal macOS file associations stay unchanged. Custom terminals must support opening folder URLs.
- Use a Windows-style context menu with a compact **Cut, Copy, Paste, Rename, and Trash** icon row, grouped commands, **Copy as Path**, and **Open in New Window**.

Existing users can install this release through **Explorer → Check for Updates…**.

Requires macOS 14 or later. One signed and notarized download supports Apple Silicon and Intel Macs.
