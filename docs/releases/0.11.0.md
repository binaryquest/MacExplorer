# Explorer 0.11.0

- Adds Check for Updates and update preferences, powered by Sparkle.
- Adds signed DMG releases for Apple Silicon and Intel Macs.
- Preserves preferences, favorites, and saved tabs when moving from the development app to io.bquick.explorer.
- Waits for active file operations to finish before restarting for an update.

Requires macOS 14 or later.
