# Explorer 0.11.3

- **Open With** lists the applications macOS registers for your selected files, with the shared default first and an **Other…** chooser. Open files in another app without changing their default association.
- **Compress to ZIP** creates an archive from selected files and folders. Files selected across search results keep their relative folder paths.
- **Extract All…** unpacks a ZIP into a named folder at your chosen location. Compression and extraction support existing-file conflicts, cancellation, and Undo; edited output is protected from Undo.
- **Properties** opens Finder's native **Get Info** window for files, folders, sidebar locations, and drives. Use **⌘I** or the right-click menu. macOS may ask you to allow Explorer to control Finder the first time.

ZIP support includes standard files, folders, and symbolic links. Password-protected archives, Finder tags, extended attributes, and resource forks are not supported in this version. Download quarantine is preserved when extracting.

Existing users can install this release through **Explorer → Check for Updates…**.

Requires macOS 14 or later. One signed and notarized download supports Apple Silicon and Intel Macs.
